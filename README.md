# 渠道埋点运营后台 Demo

[打开公网演示页](https://dinglin0925.github.io/Channels-and-Data/#links)

新版页面包含链接生成、活动 ID、历史记录、投放渠道与位置配置、追踪数据查询和 Excel 导出。活动 ID 仅在后台保存和展示；新链接使用 `mxchoice_source` 和 `mxchoice_medium`。旧版原型保存在 [`legacy/`](legacy/index.html)。

这是静态交互演示：初始访问、转化和 UID 记录均为虚构数据，新建链接与配置保存在当前浏览器。此公网演示页未连接真实采集服务或服务端数据持久化。

公网预览引用的 UMD 与其他前端资源见 [DEPENDENCIES.md](DEPENDENCIES.md)。
